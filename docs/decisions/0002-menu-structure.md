# 0002 標準のメニュー構成

- 日付: 2026-10-22
- 状態: 採用

## 決定

- ホームは各ゲーム固有。ホームの上部に **ショップ → 設定 → 情報** を並べる(ショップは課金の窓口・商品がそろっている時だけ)。
- 設定: 言語(端末に合わせる/選ぶ)・動きを減らす・購入の復元(ショップがある時)・データ削除(確認つき)。
- 情報: プライバシー・規約(URLがある時)・クレジット(権利表記。AI生成画像の表記を含める)・版。
- **画面(UI部品)は共通化せず、各アプリに残す**(ユーザー判断)。puzzle_core には、構成のモデル(`lib/meta/menu.dart`)・設定の保存(`settings.dart`)・共通文言(`menu_l10n.dart`)だけを置く。純Dartのまま(CI・依存は変わらない)。
- 層は meta(foundation の上)。foundation には追加しない。

## 根拠

1本目のアプリには設定・情報の画面が無く、ショップの入口も画面ごとにばらばらだった。2本目以降で、メニューの並び・設定の項目・文言をそろえるため。

## 保留

- UI部品(ショップ・設定・ライフ表示)の共通パッケージ化。2本目で同じ修正を繰り返すようなら、別パッケージ `puzzle_core_ui`(Flutter)を検討する。
- サウンド・振動の設定(音を入れる時に追加)。
